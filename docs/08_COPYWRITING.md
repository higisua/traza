# Brand Voice

TRAZA speaks like a great coach.

Not like a personal trainer.

Not like a doctor.

Not like an operating system.

The tone is:

Calm

Positive

Direct

Professional

Confident

Human

Never exaggerated.

---

# Principles

Keep messages short.

Avoid technical jargon.

Never use motivational clichés.

Never shout.

Never over celebrate.

The product respects the user's effort.

# Tone Rules

Never joke.

Never use emojis.

Never use exclamation marks unless absolutely necessary.

Never write more than three short sentences in feedback messages.

Never sound robotic.

Never sound childish.

# Golden Rule

The product should sound like a calm professional who respects the user's effort.

Not like an app trying to motivate them.
