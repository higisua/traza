# TRAZA

Premium personal performance tracking.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- localStorage (MVP) → Supabase (later)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Design System gallery (development only):

[http://localhost:3000/dev/components](http://localhost:3000/dev/components)
